## Project Direction

- Use the latest shadcn components, component patterns, and styling conventions when building UI.
- Prefer interactive buttons with clear icons, accessible labels, and titles/tooltips where helpful.
- Follow established frontend and backend design patterns. When a pattern is important to maintainability, document it with concise code comments.
- Split large implementations into focused components whenever the surface grows beyond a simple page.
- Create separate pages for distinct product purposes and provide a menu/navigation system that makes those purposes easy to distinguish.
